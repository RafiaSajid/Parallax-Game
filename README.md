# PARALLAX: The Shape of Space

## How the game works (the rules)
1. Every cube has ONE amber face. Turn a cube until that face points **UP**.
2. Slide that cube onto a **pressure plate**. The plate glows when a cube rests on it with the amber face up.
3. When **every** plate in the room glows, the **portal opens**.
4. Slide **one spare cube** into the portal. That completes the room. You do **not** need to move every cube into it.
5. Stars: 1 for finishing, +1 for finishing within the move par, +1 for finishing within the time par. The timer starts at your first move.
There are 3 rooms. Finish a room to unlock the next.

## Game states
MENU (how-to card) -> PLAYING <-> PAUSED. PLAYING -> SOLVED (portal animation, input locked) -> COMPLETE (completion screen, result saved). Restart from any state except the menu returns to PLAYING with a fully reset room. Cubes can only be touched in PLAYING .


## Your character
Profile > Settings > Customize opens a painter: paint a cylinder (any colour, adjustable brush), pick its top/bottom colour and save it to your account. In the game the cylinder rides the cube you select. Press C (or the Camera button) for the third-person follow camera.

## settings
Account settings (sound on/off, volume, graphics quality, reduce motion, invert camera). "Show controls panel" is a device-only preference kept in this browser's localStorage. Display name is edited on the Profile page.

## Controls
Click/tap a cube to select it (click empty space to deselect) · 1-3 pick a cube · WASD/arrows slide · Q/E roll · R/F tip · Z undo · P or Esc pause.
